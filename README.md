# 컨설팅 수행 확인서

핸드폰에서 대표님 서명을 받아 PDF로 저장하는 한 장짜리 웹앱.

- 매장명 · 대표자 · 연락처 · 담당 컨설턴트 입력
- 회차 3회 기본, 5회까지 추가
- 회차별 날짜 + 손가락 서명
- 「PDF 저장」 → A4 한 장 PDF (공유 시트 또는 다운로드)
- 입력 내용은 그 폰 브라우저에 자동 저장 (여러 매장 관리)

## 깃허브에 올리기

1. github.com → New repository → 이름 `consulting-confirm` → Public → Create
2. `Add file → Upload files` → `index.html` 올리고 Commit
3. Settings → Pages → Branch `main` / `(root)` → Save
4. 1~2분 뒤 `https://아이디.github.io/consulting-confirm/` 에서 열림

폰 홈 화면에 추가해 두면 앱처럼 씁니다.
